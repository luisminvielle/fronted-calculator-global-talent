# Employee Cost Calculator - Demo Collection

This repository contains demo versions of employee cost calculators inspired by Fronted's hiring platform. These showcase how such tools could help companies understand the total cost of employment across different countries.

## Available Demos

### 1. Original Demo (`index.html`)
- **Design**: Clean white and yellow color scheme
- **Countries**: Brazil, Philippines, Kosovo, Albania, Norway, Sweden, Germany, France, Ireland, Colombia, United States
- **Features**: Classic layout focused on calculator functionality

### 2. Alternative Demo (`calculator-variant.html`)
- **Design**: Modern teal and coral color palette with enhanced visual elements
- **Countries**: Brazil, Philippines, Ukraine, Romania, Norway, Sweden, Germany, France, Netherlands, Mexico, United States
- **Features**: Feature grid, enhanced visual design, alternative country selection

## Core Features (Both Versions)

- **Modern Design**: Clean, sleek interfaces with responsive layouts
- **Global Coverage**: Supports 11 countries across different regions
- **Multi-Currency Support**: Displays results in local currencies
- **Cost Breakdown**: Shows detailed breakdown of employment costs including:
  - Base salary
  - Taxes & social contributions
  - Benefits & insurance
  - Overhead & administration
  - Total employment cost

## Demo Nature

⚠️ **Important**: These are demonstration calculators with estimated figures. The employment cost percentages and currency conversion rates are for illustrative purposes only. For accurate employment cost calculations, please consult with local HR experts and legal professionals.

## Technical Implementation

- **Frontend**: Pure HTML, CSS, and JavaScript
- **Responsive Design**: Works on desktop and mobile devices
- **No External Dependencies**: Self-contained single files
- **Modern CSS**: Uses CSS Grid, Flexbox, and CSS custom properties
- **Cross-Browser Compatible**: Works in all modern browsers

## Usage

1. Open either `index.html` or `calculator-variant.html` in any modern web browser
2. Select a country from the dropdown
3. Choose the appropriate currency
4. Enter an annual salary amount
5. Click "Calculate" to see the estimated employment costs

## Design Inspiration

These demos were created based on Fronted's clean, modern design aesthetic and user experience patterns. The goal is to demonstrate the value of having such calculators as part of a global hiring platform, showcasing different visual approaches while maintaining core functionality.
