# Employee Cost Calculator - Demo

This is a demo version of an employee cost calculator inspired by Fronted's hiring platform. It showcases how such a tool could help companies understand the total cost of employment across different countries.

## Features

- **Modern Design**: Clean, sleek interface using white and yellow color scheme
- **Global Coverage**: Supports 11 countries including Brazil, Philippines, Kosovo, Albania, Norway, Sweden, Germany, France, Ireland, Colombia, and United States
- **Multi-Currency Support**: Displays results in local currencies
- **Cost Breakdown**: Shows detailed breakdown of employment costs including:
  - Base salary
  - Taxes & social contributions
  - Benefits & insurance
  - Overhead & administration
  - Total employment cost

## Countries Supported

1. **Brazil** - BRL currency, ~45% additional costs
2. **Philippines** - PHP currency, ~15% additional costs
3. **Kosovo** - EUR currency, ~5% additional costs
4. **Albania** - EUR currency, ~18% additional costs
5. **Norway** - NOK currency, ~25% additional costs
6. **Sweden** - SEK currency, ~35% additional costs
7. **Germany** - EUR currency, ~22% additional costs
8. **France** - EUR currency, ~45% additional costs
9. **Ireland** - EUR currency, ~15% additional costs
10. **Colombia** - COP currency, ~35% additional costs
11. **United States** - USD currency, ~25% additional costs

## Demo Nature

⚠️ **Important**: This is a demonstration calculator with estimated figures. The employment cost percentages and currency conversion rates are for illustrative purposes only. For accurate employment cost calculations, please consult with local HR experts and legal professionals.

## Technical Implementation

- **Frontend**: Pure HTML, CSS, and JavaScript
- **Responsive Design**: Works on desktop and mobile devices
- **No External Dependencies**: Self-contained single file
- **Modern CSS**: Uses CSS Grid, Flexbox, and CSS custom properties

## Usage

1. Open `index.html` in any modern web browser
2. Select a country from the dropdown
3. Choose the appropriate currency
4. Enter an annual salary amount
5. Click "Calculate" to see the estimated employment costs

## Design Inspiration

This demo was created based on Fronted's clean, modern design aesthetic and user experience patterns. The goal is to demonstrate the value of having such a calculator as part of a global hiring platform.
